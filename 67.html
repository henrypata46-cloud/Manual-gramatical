Interjección

¿Qué es una Interjección?

Una interjección es una palabra o expresión que se utiliza para expresar emociones, sentimientos, sorpresa, alegría, dolor o reacciones.

Ejemplos:

1. ¡Wow! → ¡Wow!, qué computadora tan moderna.
2. ¡Ah! → ¡Ah!, ya entendí cómo funciona la aplicación.
3. ¡Oh! → ¡Oh!, se apagó la computadora.
4. ¡Uf! → ¡Uf!, tardó mucho en descargar el archivo.
5. ¡Genial! → ¡Genial!, ya funciona el Internet.
