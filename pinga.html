Preposición

¿Qué es una preposición?

Una preposición es una palabra que sirve para relacionar dos o más palabras dentro de una oración. Puede indicar lugar, dirección, tiempo, relación, entre otras cosas.

Ejemplos:

1. Con → Uso la computadora con mis compañeros.
2. Para → Esta aplicación sirve para estudiar.
3. En → La información está en Internet.
4. Desde → Envío el archivo desde mi teléfono.
5. Sin → No puedo usar la computadora sin Internet.

Oración

Estudio con mi computadora para aprender tecnología.
